# خطوة | منصة تعليمية

منصة تعليمية عربية بواجهة متجاوبة من اليمين إلى اليسار، مبنية باستخدام Next.js وTypeScript وTailwind CSS.

تتضمن المرحلة الأولى نموذجًا لمادة الرياضيات للصف الثاني الإعدادي في مصر، الترم الأول، العام الدراسي ٢٠٢٦–٢٠٢٧. الوحدات والدروس تمارين تجريبية على أساسيات الرياضيات ولا تمثل المنهج الرسمي.

## التشغيل محليًا

يتطلب المشروع Node.js بإصدار 20.9 أو أحدث.

```sh
npm ci
npm run dev
```

افتح http://localhost:3000 وانتقل إلى «المواد الدراسية» لاختيار المادة والوحدة والدرس.

## الفحوصات

```sh
npm run typecheck
npm run lint
npm run build
```

بيانات المواد والوحدات والدروس في `lib/catalog.ts`. راجع `HANDOFF.md` لتفاصيل المسارات وإضافة محتوى جديد.
